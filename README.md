## ⚡ 프로젝트 개요

**MiroFish**는 멀티 에이전트 기술 기반의 차세대 AI 예측 엔진입니다. 현실 세계의 시드 정보(속보, 정책 초안, 금융 시그널 등)를 추출하여 고충실도의 평행 디지털 세계를 자동으로 구축합니다. 이 공간 안에서 독립적인 인격, 장기 기억, 행동 로직을 갖춘 수천 개의 에이전트가 자유롭게 상호작용하며 사회적 진화를 수행합니다. '신의 시점'에서 동적으로 변수를 주입하여 미래의 흐름을 정밀하게 추론할 수 있습니다 — **미래를 디지털 샌드박스에서 미리 시연하고, 수많은 시뮬레이션을 거쳐 최적의 결정을 내리세요**.

> 당신이 할 일: 시드 자료(데이터 분석 보고서 또는 흥미로운 소설 스토리)를 업로드하고, 자연어로 예측 요구사항을 기술하세요</br>
> MiroFish가 반환할 것: 상세한 예측 리포트와 심층 인터랙션이 가능한 고충실도 디지털 세계

### 우리의 비전

MiroFish는 현실을 매핑하는 집단지능 미러를 구축하는 데 전념합니다. 개체 간 상호작용이 촉발하는 집단 창발 현상을 포착하여 전통적 예측의 한계를 돌파합니다:

- **거시적 관점**: 의사결정자를 위한 리허설 실험실로, 정책과 PR을 제로 리스크에서 시험할 수 있습니다
- **미시적 관점**: 개인 사용자를 위한 크리에이티브 샌드박스로, 소설 결말 추론이든 상상력 탐구이든 재미있고 흥미롭게 접근할 수 있습니다

진지한 예측에서 재미있는 시뮬레이션까지, 모든 '만약'의 결과를 볼 수 있게 하여 만물의 예측을 가능하게 합니다.

1. **그래프 구축**: 현실 시드 추출 & 개인 및 집단 기억 주입 & GraphRAG 구축

3. **시뮬레이션 시작**: 듀얼 플랫폼 병렬 시뮬레이션 & 예측 요구사항 자동 분석 & 시계열 메모리 동적 업데이트
4. **리포트 생성**: ReportAgent가 풍부한 도구로 시뮬레이션 후 환경과 심층 상호작용
5. **심층 인터랙션**: 시뮬레이션 세계의 누구와도 대화 & ReportAgent와 대화

## 🚀 빠른 시작

### 방법 1: 소스 코드 배포 (권장)

#### 사전 요구사항

| 도구 | 버전 요구 | 설명 | 설치 확인 |
|------|---------|------|---------|
| **Node.js** | 18+ | 프론트엔드 런타임, npm 포함 | `node -v` |
| **Python** | ≥3.11, ≤3.12 | 백엔드 런타임 | `python --version` |
| **uv** | 최신 버전 | Python 패키지 매니저 | `uv --version` |

#### 1. 환경 변수 설정

```bash
# 예시 설정 파일 복사
cp .env.example .env

# .env 파일을 편집하여 필요한 API 키를 입력하세요
```

**필수 환경 변수:**

```env
# LLM API 설정 (OpenAI SDK 형식의 모든 LLM API 지원)
# 소비량이 크므로 40라운드 미만의 시뮬레이션부터 시도해 보세요
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL_NAME=gpt-4o

# Zep Cloud 설정
# 월 무료 할당량으로 간단한 사용이 가능합니다: https://app.getzep.com/
ZEP_API_KEY=your_zep_api_key
```

#### 2. 의존성 설치

```bash
# 모든 의존성 한번에 설치 (루트 + 프론트엔드 + 백엔드)
npm run setup:all
```

또는 단계별 설치:

```bash
# Node 의존성 설치 (루트 + 프론트엔드)
npm run setup

# Python 의존성 설치 (백엔드, 가상환경 자동 생성)
npm run setup:backend
```

#### 3. 서비스 시작

```bash
# 프론트엔드와 백엔드 동시 시작 (프로젝트 루트에서 실행)
npm run dev
```

**서비스 주소:**
- 프론트엔드: `http://localhost:3000`
- 백엔드 API: `http://localhost:5001`

**개별 시작:**

```bash
npm run backend   # 백엔드만 시작
npm run frontend  # 프론트엔드만 시작
```

### 방법 2: Docker 배포

```bash
# 1. 환경 변수 설정 (소스 코드 배포와 동일)
cp .env.example .env

# 2. 이미지 풀 및 시작
docker compose up -d
```

기본적으로 루트 디렉토리의 `.env`를 읽으며, 포트 `3000(프론트엔드)/5001(백엔드)`를 매핑합니다

> `docker-compose.yml`에 가속 미러 주소가 주석으로 제공되어 있으니, 필요시 교체하세요
